# 채미의 선물 배달 대작전

경상북도교육청 외동도서관 캐릭터 **채미**와 함께, 받는 사람이 적히지 않은 소포의 주인을 찾는 연말 책 추천 게임입니다.
휴대폰으로 열어 길을 고르고 책을 배달하면, 마지막에 나에게 맞는 도서관 책 세 권이 소포로 도착합니다.

## 실행 방법

`index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 시작됩니다.
그림·표지·소리가 모두 파일 안에 들어 있어 따로 설치할 것이 없습니다. (글꼴만 Google Fonts에서 불러오며, 인터넷이 없으면 기기 기본 글꼴로 보입니다.)

## 게임 구성

- **장면 4개**: 소포 포장 → 길 고르기 → 책 건네기 → 눈보라 → 마지막 상자
- **선물 취향 6가지**: 마지막 상자의 꼬리표(신나고 싶은 날 / 따뜻해지고 싶은 날 / 조용히 생각하고 싶은 날) × 걸어온 길의 방향(안쪽 / 바깥)
- **추천 도서 54권**: 취향 6가지 × 유아·어린이 / 청소년 / 성인 × 3권. 모두 외동도서관 추천도서·소장 도서이며 청구기호가 함께 나옵니다.
- **엔딩 9가지**: 선물 취향 6 + 배드 엔딩 2 + 숨은 엔딩 1
- **스티커 24장**: 고른 길과 취향에 따라 모으는 채미 스티커
- **소리**: 효과음과 배경음악은 음원 파일 없이 브라우저(Web Audio)에서 직접 만들어 냅니다. 화면 위 스피커 버튼으로 끌 수 있습니다.

## 책을 바꾸려면

`index.html` 안의 `const TYPES = { … }`에 취향별·연령별 책이 들어 있습니다.

```js
['제목', '저자', '청구기호', '출처']   // 출처: '6월'(추천도서) / '소장'
```

같은 제목으로 `DESC`(한 줄 소개)와 `COVER`(표지 그림)에도 항목을 넣어야 합니다.

## 개인정보

- 서버로 보내는 정보가 없습니다. 이름(별명), 모은 스티커, 배달 일지는 **그 기기의 브라우저 안(localStorage)** 에만 저장됩니다.
- 분석 도구, 광고, 쿠키를 쓰지 않습니다. 외부 연결은 Google Fonts 글꼴 하나뿐입니다.
